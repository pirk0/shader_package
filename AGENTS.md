# AGENTS.md — shader_package

Правила пакета шейдера `shader-package/1`: как шейдер описывает себя для хостов — вьюера, сборщика
TouchDesigner, стендов, — чтобы хосты не знали проектов, а проекты не знали хостов. Правила —
[`docs/format.md`](docs/format.md); проверка пакета — `python check.py <папка>`.

**Это вход для любого агента, и канон здесь один.** Claude Code читает `CLAUDE.md` — обёртку к
этому файлу.

## Как работать

- **Язык общения — русский.**
- **Правила — договор.** Каждое правило `docs/format.md` исполняет `check.py` (или эталон языка и
  строки значений) и покрывает подсаженная ошибка в `tests/check_selftest.py`. Правка правил —
  правка текста, кода и контроля разом. Совместимое уточнение остаётся версией 1, остальное —
  новая версия (`docs/format.md` §11).
- **Репо не знает ни проектов, ни хостов.** Образец `sample/` — синтетический шейдер; имён
  настоящих проектов и хостов в правилах, коде и образце нет. Откуда правила пришли — только в
  `docs/decisions.md`.
- **Коммит согласуется каждый раз**, пуш — вместе с ним. Удалённый репо —
  `https://github.com/pirk0/shader_package`.
- **Перед коммитом — все стенды зелёные**, блоки с glslang — с `GLSLANG=`.
- Python 3 без сторонних пакетов: правила исполняет и хост на Python внутри чужой программы.
- В коде — назначение, единицы и одна строка «что сломается»; развёрнутое — в `docs/`.

## Раскладка

| путь | что |
|---|---|
| `check.py` | проверка пакета: все ошибки разом, правилом и местом |
| `expr.py` | эталон языка выражений: разбор, типы, значение, шаблоны |
| `values.py` | эталон строки значений и наборов |
| `knobs_rules.py` | правила `knobs.json` и сверка с общей вкладкой шейдера |
| `vectors/expr.json` | векторы языка — договор для каждой реализации |
| `sample/` | образец пакета: два пасса, картинка, пропуск, область, время, указатель, предупреждение, набор |
| `tests/` | стенды |
| `docs/` | правила, решения, задачи |

## Стенды (из корня репо)

```
python tests/vectors_check.py    # язык на векторах; подмножество GLSL (GLSLANG=); 10 контролей
python tests/check_selftest.py   # проверка пакета: образец чист, 62 подсаженных ошибки, битый вход
python tests/sample_check.py     # правда объявлений образца; сборка вкладок (GLSLANG=)
```

Что каждый стенд судит — шапка его файла. Без `GLSLANG=<путь к glslangValidator>` блоки сборки
говорят, что не работали, и не краснеют.
